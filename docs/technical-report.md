# 基于ESP32-S3与小智AI的智能哮喘喷雾计量装置技术报告

## 一、项目概述

设备以ESP32-S3为主控，搭载SDP32高精度差压传感器实现喷雾药量精准计量，通过BLE与WiFi实现手机APP数据联动，集成小智AI开源框架提供云端智能问答，可以覆盖用药监测、数据统计、健康咨询、用药指导、异常提醒等场景。

## 二、小智AI集成方案

### 2.1 框架简介

小智AI（xiaozhi-esp32）为开源AI语音交互框架（GitHub: [78/xiaozhi-esp32](https://github.com/78/xiaozhi-esp32)），基于ESP-IDF 5.3开发，架构如下：

```
麦克风(I2S) ──→ ESP32-S3 ──WebSocket/Opus──→ 云端服务器
                   │                              ├── ASR（SenseVoice，5语言）
                   │                              ├── LLM（DeepSeek/Qwen/豆包）
                   │                              └── TTS（火山引擎/CosyVoice）
扬声器(I2S) ←── ESP32-S3 ←─── 音频流 ──────── 云端返回
```

设备端仅负责音频采集/播放与离线唤醒词检测（ESP-SR，"你好小智"），ASR、LLM推理、TTS均在云端完成，设备须**联网使用**。

### 2.2 控制台配置（xiaozhi.me）

小智AI的提示词、角色、模型等均在Web控制台配置，无需修改固件：

| 配置项 | 配置位置 | 说明 |
|---|---|---|
| 角色设定（System Prompt） | https://xiaozhi.me/console/ → 角色配置 | 定义AI身份、专业领域（如"哮喘用药指导专家"）、回答风格与知识边界 |
| 大模型选择 | 同上 → 角色配置 | 可选 DeepSeek V3 / Qwen 2.5 / 豆包 1.5 Pro / Qwen Max 2.5 |
| TTS音色 | 同上 → 角色配置 | 试听并选择播报语音 |
| 设备注册 | https://xiaozhi.me/console/ → 设备管理 | 通过设备验证码绑定终端 |
| 唤醒词 | ESP-IDF menuconfig（编译时） | 可选约25个预设唤醒词；自定义唤醒词需向乐鑫申请 |
| 声纹识别 | 控制台 → 智能体 → 声纹识别 | 添加说话人，实现多用户识别 |

> 本项目通过角色配置将System Prompt设为哮喘用药专业领域，限定回答范围，确保输出专业、安全。

### 2.3 本装置AI功能（一些设想）

- **用药问答**：用法、剂量、间隔、场景方案等专业咨询
- **数据解读**：用药数据分析，识别过量/不足/频繁/漏用等异常
- **健康科普**：过敏原规避、饮食作息、换季预防等
- **用药提醒**：定时提醒

## 三、硬件清单

（可以选购集成化模块）

| 序号 | 模块 | 型号/参数 | 功能 |
|---|---|---|---|
| 1 | 主控 | ESP32-S3-WROOM-1（8MB Flash + 8MB PSRAM） | 传感采集、标定运算、BLE/WiFi通信、本地规则引擎、整机调度 |
| 2 | 差压传感器 | SDP32（I2C，±500Pa） | 喷雾压差检测，标定换算药量与时长 |
| 3 | 按压检测 | 微型微动开关 | 触发采集启停，记录用药起止时间 |
| 4 | 显示 | 0.96寸 I2C OLED | 药量、时长、用药次数、AI回复文字 |
| 5 | 语音交互 | INMP441 I2S麦克风 + MAX98357 I2S功放 + 扬声器 | 语音采集与播放（小智AI标准音频链路） |
| 6 | 提醒 | 无源蜂鸣器 + 微型震动马达 | 用药提醒、异常预警 |
| 7 | 供电 | 3.7V 800mAh锂电池 + TP4056 | USB-C充电，便携供电 |
| 8 | 通信 | BLE 5.0 + WiFi 2.4GHz（板载） | BLE同步APP数据；WiFi调用云端小智大模型 |
| 9 | 存储（可选） | Micro SD（SPI） | 本地用药日志与对话记录 |

## 四、核心功能

### 4.1 精准计量
- SDP32差压检测 → 标定算法换算药量，区分有效喷雾与误触
- 单次/日累计/历史频次全程统计

### 4.2 数据可视化与同步
- OLED本地显示；BLE同步APP；TF卡 + 云端双存储

### 4.3 AI智能服务
- 联网：全场景哮喘用药问答、数据智能分析、应急指导
- 离线：预设模板匹配 + 本地规则异常判定

### 4.4 提醒与预警
- 定时用药提醒；用药异常本地实时预警；蜂鸣器/震动/屏幕/语音多维度

### 4.5 低功耗
- Deep Sleep + 开关唤醒；USB-C充电

## 五、技术可行性

| 模块 | 依据 |
|---|---|
| SDP32喷雾计量 | I2C标准外设，压差-药量标定经实验验证 |
| BLE/WiFi + APP | ESP32-S3原生支持，协议栈与手机SDK成熟 |
| 云端小智AI | WebSocket音频流 + API调用，设备仅做终端 |
| 本地规则引擎 | 纯逻辑判定，资源占用极小 |
| 低功耗待机 | Deep Sleep + GPIO唤醒 |
| 离线预设问答（模板匹配） | 类似小爱同学离线模式：固件内置预设问答库（常见用药问题→标准回复），通过关键词匹配返回。本装置离线模式下即为此方案 |
| 离线语音唤醒 | ESP-SR支持约25个预设唤醒词，含"你好小智" |
| 离线通用ASR | ESP-SR仅支持关键词唤醒，不支持通用语音转文字 |
