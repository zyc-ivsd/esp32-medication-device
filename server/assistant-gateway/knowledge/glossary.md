# 术语表

回答时请统一使用这些说法，不要自造近义词。

## 使用动作

设备检测到的一次使用行为，协议中 `event_type = 1`。**不等于服药。**

## 疑似无效

设备标记为可疑的事件，协议中 `event_type = 2`。可在历史记录中查看原始信息。

## 其他事件

协议中 `event_type = 3`，既不是使用动作也不是疑似无效，单独统计。

## 时间未知

记录的时间戳为 0，无法确定发生时间，**不计入按日统计**。

## 未来时间

记录时间晚于当前时间，通常由设备时间不准造成，**不计入按日统计**。

## 演示数据

内置的合成记录，用于体验功能，不代表真实用药情况。

## 原型时间文本

早期硬件原型通过 BLE 发送的时间文本，保存在独立数据库，**不进入**正式历史、统计和助手摘要。
