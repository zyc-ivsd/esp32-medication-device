# 数据存放与隐私

## 记录保存在哪里？

记录保存在**手机本机**的 SQLite 数据库里。设备记录、演示数据、早期原型时间文本**分别存储**；清除演示数据不会删除设备记录。

## 在线助手会发送什么？

只发送**本次问题** + **统计摘要**。具体发哪几个字段写在提示词的载荷里（`assistant_prompt.dart`），
运行时原话见语料 `privacy.upload`；**不发送**原始记录、时间戳明细、设备标识或历史对话。

## 用自己模型的 API Key 安全吗？

填写自己的模型 Key 时，它存进 [`flutter_secure_storage`](../../../mobile_app/lib/assistant/assistant_credentials.dart)
（Android Keystore / iOS Keychain），**不用 `shared_preferences` 明文存**；
**不会发送给团队服务器，也不会写进日志**，删掉那条配置即清除。
仓库规则同样禁止把任何 Key 写进源码、APK、构建参数或提交到仓库。

## 如何导出与换手机？

在历史记录页使用"导出 CSV"。数据只存在本机，换手机前请先导出；换机不会自动同步历史记录。

## 没有网络时还能用吗？

可以。本地规则助手完全离线，切回"本地摘要"即可，统计与历史不受影响。凭据存在安全存储里，
所以重新打开 App 不用重填；但**不点"在线"就不会联网**。

## 换手机或重装 App 后设备会重复吗？

装置按 `device_id + seq` 去重。重新同步同一批记录不会在历史里重复出现。
