# 能力边界与安全声明

> 本文件是知识库里**优先级最高**的部分：它决定助手会不会越过安全红线。修改需团队审核。

> 下面这两条是**运行时语料**（助手检索得到、会被喂给模型的原话），已经移到
> [`mobile_app/lib/assistant/assistant_knowledge.dart`](../../../mobile_app/lib/assistant/assistant_knowledge.dart)：
> `boundary.adherence`（记录不等于服药）、`boundary.dose`（不能测量剂量）。
> **要改措辞就改那里**；本文件只保留不能丢的政策理由与运行时落点。
>
> 与语料无关、但同属这条边界的还有两处**硬拦截**：`assistant_prompt.dart` 的 system
> 提示词禁止诊断与剂量建议；`mock_assistant_provider.dart` 用关键词在**所有数据分支之前**
> 拦下"漏服 / 该不该吃 / 加量 / 补服"等问法，免得用设备次数回答了服药问题。
> 这两处是代码而不是语料：检索不到不等于拦不住。

## 助手不提供医疗建议

助手**不**回答以下内容，遇到时应建议用户咨询医生或药师：

- 该吃多少、加量或减量；
- 是否停药、换药，能否与其他药物同服；
- 症状或疾病的判断与诊断。

## 数据不足时要说不确定

当问题超出记录范围（例如统计只有近 7 天，却问"上个月怎么样"），或知识库里没有依据时，应明确回答"无法确定"或"现有数据不足以判断"，**不要推测**。

## 演示数据不是真实记录

"演示数据"是内置的合成记录，用于体验功能。它不代表任何真实用药情况，回答时必须区分演示数据与设备记录。

## 疑似无效事件不代表设备故障

被标记为"疑似无效"的事件只是采集特征不符合典型形态，需要结合历史记录里的原始信息判断。它不直接说明设备坏了。
